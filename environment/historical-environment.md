# Historical software environment record

## Purpose and limits

This document is a cleaned summary of `software_environment_versions.xlsx`, audited on 2026-08-05. The workbook was created on a different local machine and scanned an earlier code directory whose filenames do not exactly match the scripts in this repository. It is retained as a historical guide only.

It is **not** a locked runtime, a saved session, or proof of the exact environment that generated the earlier figures. No local file paths, account names, affiliations, or author information are retained here.
