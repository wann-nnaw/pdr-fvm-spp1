# pdr-fvm-spp1

Code accompanying a computational reanalysis of proliferative diabetic retinopathy fibrovascular membranes (PDR-FVM), focused on an SPP1-associated cross-state macrophage programme.

## Scope of this repository

This private repository contains only the ten main analysis scripts and documentation. It does **not** contain raw data, intermediate R objects, generated results, figure source files, author information, institutional information, or a software lock file.

The primary public datasets are:

- GSE165784: primary PDR-FVM single-cell dataset.
- GSE102485: exploratory bulk RNA-seq tissue-level comparison.

GSE102485 is affected by disease-status and tissue-source confounding. It must not be interpreted as independent validation or diagnostic validation.

## Current reproducibility status

This repository is a transparent code archive, not yet a fully rerun reproducibility release.

- The currently available local input folder for GSE165784 is incomplete for a fresh reconstruction of the five-sample analysis. The missing original inputs must be restored from GEO before rerunning.
- The archived result files were mainly generated from June to July 2026, while the copied main scripts were last updated in August 2026. The final Figure 1–7 TIFF files were updated later still. Therefore, the current repository does not claim that the final manuscript figures were generated by a complete run of these exact scripts.
- A future reproducibility release must add a data-download step, freeze the R and Python environments, rerun from raw public data, and compare regenerated outputs against the final submission materials.
